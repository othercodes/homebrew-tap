# othercodes Homebrew tap

Homebrew casks for othercodes command-line tools, for macOS and Linux.

## Tools

| Tool | Description | Install |
|---|---|---|
| [tmetric](https://github.com/othercodes/tmetric-cli) | Unofficial CLI and TUI for TMetric time tracking | `brew install othercodes/tap/tmetric` |

## Usage

Install a tool. Homebrew adds the tap the first time:

```sh
brew install othercodes/tap/<tool>
```

Upgrade or remove it:

```sh
brew upgrade <tool>
brew uninstall <tool>
```

Each tool installs on its own; the tap is only the list of what you can install.

## Notes

- The binaries are not notarized by Apple. The casks clear the macOS quarantine attribute on install, so Gatekeeper does not block them.
- The casks in `Casks/` are generated by each tool's release workflow (GoReleaser). Do not edit them by hand: the next release overwrites them.
